# Ergasias.info - Γραφείο Ευρέσεως Εργασίας

Modern recruitment agency website for **ΛΟΥΚΙΑ ΤΣΙΩΤΑ & ΣΙΑ Ο.Ε.**

Built with Astro 4, Tailwind CSS v3, TypeScript, and Decap CMS.

## Deploy to Netlify

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/christoskostouros/ergasias-website)

## After Deploy

1. Enable **Netlify Identity** (Site Settings → Identity → Enable)
2. Access CMS at `yoursite.netlify.app/admin`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
